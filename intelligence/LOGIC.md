# Logic (intelligence behind the programs)

All quantitative work shares `internal/js/math.js`. Study type reconfigures workstreams in `internal/js/studies.js`. Kits live in `internal/js/kits.js`. The wired chain is `internal/js/pipeline.js`. The client board is `internal/js/synthesis.js`.

## Gates (order)

1. **Discovery intake** — facts and the story they believe. The story is not the cause.  
2. **Structured diagnosis** — competing causes. KEEP / WEAK / KILL.  
3. **Financial due diligence** — liquidity, DSCR, cash cycle, quality of earnings, NPV. STOP / CAUTION / GO.  
4. **Matched diagnostic kit** — growth, margin/capital, operations, capital project, or supply.  
5. **Quantified tree, sensitivity, Monte Carlo, matrix** — only on the surviving thesis.  
6. **Roadmap / packet / resolution dashboard** — unique constraints, 90-day load.

## Formulas (Excel equivalents)

| Program | Excel | Note |
| --- | --- | --- |
| NPV | `=NPV(rate, CFs)+t0` | Value after WACC |
| IRR | `=IRR(CFs)` | Compare to WACC |
| MIRR | `=MIRR(CFs, finance, reinvest)` | Realistic reinvestment |
| WACC | `E/(E+D)*Re + D/(E+D)*Rd*(1-tax)` | Discount rate |
| DSCR | `EBITDA/(interest+principal)` | Coverage gate |
| CCC | `DSO+DIO-DPO` | Cash trapped |
| CPI / SPI | `EV/AC`, `EV/PV` | Live project |
| Throughput T | `MIN(demand, cap*OEE)*contrib*periods` | Constraint, not busy |
| NP (TOC) | `T-OE` | Not local efficiency |
| OLS | `=LINEST(y,x,TRUE,TRUE)` | R² is a finding |
| Matrix | `=SUMPRODUCT(weights, scores)` | Not a vote |
| Risk EMV | `p*impact` | Register |
| Monte Carlo | Seeded iterations | Not `RAND()` |

## Uniqueness rule

`synthesis.js` drops duplicate constraint labels across diagnosis, diligence, throughput, project, and supply. Killed stories are listed once so they are not staffed again. Implementation lanes come from the study type, not a second template.

## What is not in the algorithm

Public peek toys (win rate, three-year NPV, CPI/SPI) are demonstrations. They do not write the engagement bus. The Growth diagnostic glimpse does write `isi_input` in the browser and can feed scoring — still not the full internal suite.
