# Access without corrupting files

## Do

- Open pages in the **browser**. Bookmark URLs. Type numbers into forms. Print/PDF from the page.
- Change **words** in `intelligence/EDITABLE-COPY.md` (then ask Desktop to sync `website/content.json`).
- Replace **photos** in `website/images/` using the **same file name**.
- Run grouped work from `/internal/programs.html` or `/internal/pipeline.html`.
- Run one formula from `/internal/toolbox.html`.

## Do not

- Save a browser page as HTML back into the repo.
- Edit `internal/js/math.js`, `kits.js`, `pipeline.js`, `studies.js` for a wording tweak.
- Paste Writer/Word/10Web exports over live pages.
- Advertise `/internal/` or `/client/` URLs.
- Name employers or clients on public pages.
