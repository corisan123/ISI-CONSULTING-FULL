# How to get the best outputs from Desktop Cursor

Work stays in this GitHub repo. Cloudflare publishes **only** after a commit and push to `main`. Clicking the Pages preview does not publish new files.

## What to say

1. Name the **lane**: public site, internal bench, or client resolution room. Never mix Truth Collective into this repo.
2. Name the **artifact**: “homepage copy,” “resolution dashboard,” “MECE tree,” “intake form.”
3. Name the **constraint**: commercial, cash, throughput, live project, supply, coaching, venture.
4. Say **protect** when you mean: no live engines on marketing pages, no employer names, spell out Business Development.
5. Ask to **commit and push** only when you are ready for isiconsults.com to change.

## What not to say

- Do not ask this Desktop session to patch WordPress, 10Web, Writer, or Vercel dumps as if they were the live site.
- Do not ask to paste Monte Carlo, trees, or matrices onto the public homepage as working calculators.
- Do not name client or former employers on public pages without a signed waiver.

## Simple wording

Edit `intelligence/EDITABLE-COPY.md`. Then say: “Sync EDITABLE-COPY into website/content.json.” Homepage headlines with `data-copy` update after deploy.

## Engagement run (staff)

1. `/internal/index.html` — save company, pick constraint family.  
2. `/internal/study.html` — pick study type (workstreams spawn).  
3. `/internal/pipeline.html` — run the wired chain, **or** `/internal/toolbox.html` for one formula.  
4. `/client/resolution.html` — what you put on the screen in the room.

Numbers stay in this browser until you replace placeholders in consultation. Nothing is posted to a server from these pages.
