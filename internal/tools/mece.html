MECE issue trees

MECE is the floor: buckets do not overlap and nothing material is missing. It is not the engagement. Depth means each branch ends on a testable cause. Insight means the tree is built for this constraint, not a generic profit tree every firm draws. Select a kit, audit overlaps, then write the pyramid close.
